# Mobile Build & Sync Loop

BudgetWise uses **Capacitor** to wrap the same Vite + React web app into native Android and iOS applications.

## Prerequisites

- **Android**: [Android Studio](https://developer.android.com/studio) with SDK 34+
- **iOS** (macOS only): Xcode 15+ and CocoaPods

## 2-Step Build Loop

After making changes to the web app, synchronize all platforms with:

```bash
npm run build        # 1. Build the web app into dist/
npx cap sync         # 2. Copy assets & sync native plugin configs
```

That's it. `cap sync` copies the fresh `dist/` output into each native project and updates native dependency declarations.

## Platform-Specific Builds

```bash
# Android — opens Android Studio (then run on emulator/device)
npx cap open android

# iOS (macOS only) — opens Xcode
npx cap open ios
```

## Adding a New Capacitor Plugin

```bash
npm install @capacitor/plugin-name
npx cap sync
```

## Live Reload (Development)

For faster iteration during development:

```bash
npx cap run android --livereload-url=http://YOUR_IP:5173
```

Replace `YOUR_IP` with your machine's LAN IP (the phone/emulator needs to reach it).

## Project Structure

```
budget-app/
├── android/          # Android native project (gradle)
├── ios/              # iOS native project (Xcode)
├── src/              # Web app source (React + Vite)
├── dist/             # Built web output (auto-generated)
├── capacitor.config.ts
└── README_MOBILE.md
```

> **Note:** The `android/` and `ios/` directories are generated by `npx cap add android` / `npx cap add ios`. They should be committed if you want other developers to build without re-running `cap add`.
